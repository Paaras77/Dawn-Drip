Prompt 8
================================================================================
Category Filter & Live Search:
   - Combine filter chips (All, Hot, Cold, Snack) and live search input so they work simultaneously.
   - When filtering, animate cards gently (fade out/in using opacity and transform).
   - If no items match the combined query, display an empty-state message inside the grid:
     `<div class="empty-results"><p>Nothing by that name. Try 'latte' or 'brownie'?</p><button id="btn-clear-search" class="btn-outline">Clear search</button></div>`
   - Clicking "Clear search" resets the input, sets filter to "All", and re-renders all cards.

2. Slide-In Cart System:
   - Cart state management: Array of `{ id, name, price, qty }`.
   - Persistence: Save cart state in `localStorage` under key `dusk_drip_cart`. Wrap all `localStorage.getItem` and `setItem` calls in `try...catch` blocks.
   - On page load, initialize cart from `localStorage` and render badge count.
   - "Add to Order" button on cards:
     * Adds item or increments qty if already present.
     * Updates navbar `#cart-count` badge.
     * Triggers a toast notification: "Added [Item Name] to your order."
   - Cart Drawer UI:
     * Render item rows with title, individual item price, decrement (-), quantity, increment (+), and trash/remove button.
     * Show live subtotal at the bottom.
     * "Place order" button: clears cart from state and `localStorage`, displays an inline success message: "Order in. Your cup is dripping its way to you.", and closes drawer after 2.5 seconds.
   - Open/close drawer triggers: Cart button in nav opens, close button / backdrop click / Escape key closes.

3. Mobile Navigation & Smooth Scroll:
   - Toggle mobile nav overlay when clicking the hamburger button; toggle `aria-expanded` and lock body scroll when open.
   - Clicking any nav link closes the mobile menu smoothly.
   - IntersectionObserver on <section> elements to add an `.active` class to the matching nav link as the user scrolls.
